# پنل کاری مازندشت
Python 3.10+ لازم است. نصب و اجرا:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

پنل روی درگاه 8000 اجرا می‌شود. فایل‌های بارگذاری‌شده در پوشه محلی uploads ذخیره می‌شوند، وارد Git یا داده‌های اکسل نمی‌شوند و با حذف محیط ممکن است از بین بروند. این نسخه احراز هویت ندارد؛ آن را در شبکه عمومی بدون محافظ دسترسی منتشر نکنید. گزارش اولیه در فایل `گزارش-بررسی.md` است.
